# ビジョン

## 目的

スマホで、気が向いたときに興味のあるテーマの問題を解き、間隔を空けた復習で知識を定着させる。問題は LLM で生成し、覚えるにつれて新しい問題が増えていく。

## 想定する利用者

- 主な利用者は開発者本人。スキマ時間にスマホで学びたい社会人
- public に公開し、他の人も使えるようにする。進捗は利用者ごとに保存する

## コンセプト

- **テーマを選んで学ぶ**: 「社会」「日本史」「世界史」「建築」「絵画」など複数のテーマを用意する。最初は少ないテーマから始める
- **範囲を絞って学ぶ**: テーマは、一つの問いで貫かれたサブカテゴリ（日本史 > 日本の宗教はどう移り変わったか など）に分ける。全体・テーマ・サブカテゴリのどの範囲でも達成状況が見え、そこから学習を始められる（ADR-0001, ADR-0002）
- **忘れる前に復習する**: Anki のような間隔反復で、覚えるべきものを覚えるまで繰り返す（ADR-0002）
- **覚えたら問題が増える**: 定着度に応じて新しい問題が解放される（ADR-0002）
- **知識をつなげて覚える**: 解説（なぜその答えか）とは別に「つながり」を示す。時代・地理・因果・人物・比較の軸で、ほかの知識と結びつけ、関連する問題へたどれるようにする。未解放の関連問題は伏せて予告する（ADR-0001）
- **進捗が見える**: テーマごとに定着度（★）の分布と、次の解放までの残りを示す（ADR-0002）
- **飽きさせない**:
  - 1 回は短く（5 問程度）
  - 出題形式は問題の内容に合わせる（年代 → 並べ替え、作品 → 画像問題、用語 → 4 択など）
  - 意外な豆知識（へぇ）は、あるときだけ添える
  - テーマ同士を時代でつなぐ（年表）。覚えたものが図鑑として貯まる
  - ストリークなどのゲーム要素は控えめにし、義務感を生まない
- **画像や図で理解を助ける**: 本物の絵画・建築の画像や、地図・年表などの図を使う（ADR-0004）
- **学習データで問題が良くなる**: 苦手分野や誤りのありそうな問題を Claude が把握し、問題を追加・修正する（ADR-0006）

## やらないこと

- アプリ実行時の LLM による問題生成（ADR-0001）
- ログインの必須化（ADR-0007）
- 資格試験対策など、網羅性や正確性を保証する学習教材としての提供
- ランキングや対戦などの他の利用者との競争要素
