# Architecture Decision Records

このプロジェクトのアーキテクチャ上の意思決定を記録する。

## 運用ルール

- 1 つの決定につき 1 ファイル。`NNNN-kebab-case-title.md`（4 桁連番 + 英語ケバブケース）で作成し、タイトルは日本語で書く
- 決定を覆す場合は既存 ADR を書き換えず、新しい ADR を作成して旧 ADR のステータスを「置換（→ NNNN）」にする
- ステータスや日付の更新、誤字修正などの軽微な変更は既存 ADR を直接編集してよい
- ADR を追加・更新したら下の一覧も更新する

## ステータス

| ステータス | 意味 |
|---|---|
| 提案 | 検討中。合意前 |
| 承認（未実装） | 採用は決定したが、まだ実装していない |
| 承認（実装済み） | 採用し、実装も完了した |
| 却下 | 検討したうえで採用しなかった |
| 廃止 | 無効になった（後継なし） |
| 置換（→ NNNN） | 別の ADR に置き換えられた |
