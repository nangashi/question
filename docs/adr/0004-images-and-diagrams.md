# 0004. 画像は PD / CC ライセンスのものを使い、図は SVG / Mermaid で作る

- ステータス: 承認（未実装）
- 日付: 2026-09-25
- 関連: ADR-0001

## 背景

絵画や建築の問題では、画像があると理解や記憶の助けになる。地図・年表・構造図なども図があると分かりやすい。公開する場合は著作権と正確性に配慮する必要がある。

## 決定

- 絵画: パブリックドメインの作品画像を Wikimedia Commons などから使う
- 建築などの写真: CC ライセンス（CC-BY / CC-BY-SA など）の画像を使い、クレジットを表示する
- 図（地図・年表・構造図・関係図）: LLM に SVG や Mermaid で描かせる
- 各画像について出典 URL・作者・ライセンスを問題データに持たせ、アプリに表示する
- AI 生成画像は、実在の作品や建築を示す用途には使わない

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| **PD / CC 画像 + LLM による SVG 図（採用）** | 本物の画像で学べる。図は軽量で修正しやすい | ライセンス管理が必要 |
| AI 画像生成 | 自由に作れる | 実在しない「それっぽい」絵や建築で誤解を招く |
| 画像なし | 手間がない | 絵画・建築テーマの学習効果が大きく落ちる |

## 結果

- 良い影響: 画像問題（「この建築は？」など）を出題でき、飽きにくくなる
- 悪い影響: 画像の選定・ライセンス確認の手間が増える
- リスク: 画像と問題の取り違え → 生成時の検証パスと報告ボタン（ADR-0001）で対処する

## 未解決事項

- 画像をリポジトリに同梱するか、外部 URL で参照するか（容量・リンク切れ・表示速度のトレードオフ）
