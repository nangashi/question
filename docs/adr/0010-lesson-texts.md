# 0010. サブカテゴリに読み物を付け、節ごとに問題を解けるようにする

- ステータス: 承認（未実装）
- 日付: 2026-09-25
- 関連: ADR-0001, ADR-0002, ADR-0008

## 背景

前提知識の少ない分野（例: 西洋美術史）では、知識カード単位の問題だけを解いても、個々の知識がサブカテゴリの問いや全体の流れとどうつながるのかが分からない。一方、背景知識のある分野（例: 日本史）では、いきなり問題を解いても理解できる。

## 決定

- すべてのサブカテゴリに、教科書のような文章（読み物）を付ける。読むかどうかは学習者が選べる（任意）
- 読み物は節に分け、各節が扱う知識カードを明示する。1 節を読み終えたら、その節の知識カードに関わる問題（3〜5 問）を解ける
- 解答後の画面では、問題が参照する知識カードを含む節を、画面を移動せずにその場で展開して読み返せる（出題の流れを途切れさせないため。ADR-0008 のつながりと同じ考え方）
- 読み物は Markdown で書く（書きやすく、差分でレビューしやすいため）

```
content/<theme>/<category>.md    ← 読み物
content/<theme>/<category>.json  ← 知識カードと問題（ADR-0008）
```

```markdown
# 印象派とその後            ← サブカテゴリの題（任意）

## 写真とサロン             ← 節の見出し（`## ` で区切る）
<!-- items: pt-impressionism-academy, pt-impressionism-photography -->
本文（段落、**強調**）……
```

  - `<!-- items: ... -->` に、その節が扱う知識カードの ID を書く。節の ID は出現順（1, 2, …）とする
  - 1 節は 400〜800 字、1 サブカテゴリ全体で 10〜15 分で読める分量を目安にする
  - 読み物の文章も執筆ガイド（`docs/content-guide.md`）と事実確認の対象とし、確認メモに含める
- 読み物に書かれていない知識を問題で問わない。問題は、読み物の内容を思い出すための手がかりとする
- 検証（`pnpm validate`）では、節が参照する知識カードの存在を確かめる。どの節にも含まれない知識カードは警告する

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| **サブカテゴリごとの読み物＋節ごとの問題（採用）** | 流れの中で知識を位置づけられる。読む→思い出す、の順で定着しやすい | 読み物を書き、確認する手間が増える |
| 知識カードの概要・なぜを充実させるだけ | 実装が不要 | 知識カード同士をつなぐ「流れ」は伝わらない |
| 外部の教材へのリンク | 手間が少ない | 内容と問題が対応しない。品質を管理できない |

## 結果

- 良い影響: 前提知識がなくても、読み物で流れをつかんでから問題に進める。問題の「細切れ感」が減る
- 悪い影響: コンテンツの作成量が増える（1 サブカテゴリあたり 3,000〜8,000 字）
- リスク: 読み物の誤り → 知識カードと同じく資料で確認し、確認メモに残す
